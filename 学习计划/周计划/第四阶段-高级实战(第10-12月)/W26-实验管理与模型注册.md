#### 实验追踪基础

```python
import mlflow
import mlflow.sklearn
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score, f1_score
from sklearn.model_selection import train_test_split

# 设置Tracking Server地址（本地server）
mlflow.set_tracking_uri("http://localhost:5000")

# 设置实验名称（不存在则创建）
mlflow.set_experiment("titanic-classification")

# 创建一个实验运行
with mlflow.start_run(run_name="rf_baseline_v1"):
    # 记录超参数
    mlflow.log_param("n_estimators", 100)
    mlflow.log_param("max_depth", 10)
    mlflow.log_param("min_samples_split", 2)

    # 或一次性记录多个参数
    params = {
        "n_estimators": 100,
        "max_depth": 10,
        "min_samples_split": 2,
        "random_state": 42,
    }
    mlflow.log_params(params)

    # 训练模型
    model = RandomForestClassifier(**params)
    model.fit(X_train, y_train)

    # 预测和评估
    y_pred = model.predict(X_test)
    accuracy = accuracy_score(y_test, y_pred)
    f1 = f1_score(y_test, y_pred, average="weighted")

    # 记录指标
    mlflow.log_metric("accuracy", accuracy)
    mlflow.log_metric("f1_score", f1)

    # 记录时序指标（如每个epoch的loss）
    for epoch in range(1, 11):
        train_loss = 1.0 / epoch  # 模拟递减loss
        mlflow.log_metric("train_loss", train_loss, step=epoch)

    # 记录产物（任意文件）
    import matplotlib.pyplot as plt
    from sklearn.metrics import confusion_matrix, ConfusionMatrixDisplay

    cm = confusion_matrix(y_test, y_pred)
    disp = ConfusionMatrixDisplay(cm)
    disp.plot()
    plt.savefig("confusion_matrix.png")
    mlflow.log_artifact("confusion_matrix.png")

    # 记录模型
    mlflow.sklearn.log_model(model, "model")

    # 添加标签
    mlflow.set_tag("model_type", "RandomForest")
    mlflow.set_tag("dataset", "titanic")
    mlflow.set_tag("author", "your_name")

    print(f"Run ID: {mlflow.active_run().info.run_id}")
    print(f"Accuracy: {accuracy:.4f}, F1: {f1:.4f}")

# 运行结束后自动关闭
```

#### Model Registry概念

```
Model Registry层次结构：

Registered Model（注册模型）
├── Model Version 1 (v1)
│   └── Stage: Production
├── Model Version 2 (v2)
│   └── Stage: Staging
├── Model Version 3 (v3)
│   └── Stage: None (刚注册)
└── ...

模型阶段（Stage）生命周期：
None → Staging → Production → Archived

- None:      刚注册，尚未评估
- Staging:   正在测试/验证中
- Production: 已通过验证，在生产环境使用
- Archived:  已退役，不再使用
```

#### 模型阶段管理

```python
import mlflow
from mlflow.tracking import MlflowClient

client = MlflowClient()
mlflow.set_tracking_uri("http://localhost:5000")

# 列出所有注册模型
registered_models = client.search_registered_models()
for rm in registered_models:
    print(f"模型: {rm.name}, 最新版本: {rm.latest_versions}")

# 获取模型的所有版本
versions = client.search_model_versions("name='titanic-classifier'")
for v in versions:
    print(f"版本: {v.version}, 阶段: {v.current_stage}, 精度: {v.description}")

# 将模型阶段从None切换到Staging
client.transition_model_version_stage(
    name="titanic-classifier",
    version=2,
    stage="Staging",
    description="通过验证测试，移至Staging",
)

# 从Staging切换到Production
client.transition_model_version_stage(
    name="titanic-classifier",
    version=2,
    stage="Production",
    description="A/B测试通过，部署到生产环境",
    archive_existing_versions=True,  # 自动将旧Production版本归档
)

# 添加模型描述
client.update_model_version(
    name="titanic-classifier",
    version=2,
    description="GBC模型，accuracy=0.85，用于生产环境",
)
```

#### 模型签名（ModelSignature）

```python
from mlflow.models.signature import ModelSignature, infer_signature
from mlflow.types.schema import Schema, ColSpec

# 方法1：自动推断签名
signature = infer_signature(X_train, model.predict(X_train))

# 方法2：手动定义签名
input_schema = Schema([
    ColSpec("double", "age"),
    ColSpec("double", "fare"),
    ColSpec("integer", "pclass"),
    ColSpec("integer", "sex_encoded"),
])
output_schema = Schema([ColSpec("integer", "survived")])
signature = ModelSignature(inputs=input_schema, outputs=output_schema)

# 记录带签名的模型
mlflow.sklearn.log_model(
    model,
    "model",
    signature=signature,
    input_example=X_train[:3],  # 提供输入示例
)
```

```python
import mlflow

def run_pipeline():
    """多步骤训练Pipeline"""
    mlflow.set_experiment("titanic-pipeline")

    with mlflow.start_run(run_name="full_pipeline") as parent_run:
        # 步骤1：数据准备
        data_prep_run = mlflow.run(
            ".",
            entry_point="data_prep",
            parameters={"raw_data_path": "data/raw/titanic.csv"},
        )

        # 步骤2：模型训练（使用步骤1的输出）
        train_run = mlflow.run(
            ".",
            entry_point="train",
            parameters={
                "data_path": "data/processed/titanic_processed.csv",
                "n_estimators": 200,
                "max_depth": 5,
            },
        )

        # 步骤3：模型评估
        eval_run = mlflow.run(
            ".",
            entry_point="evaluate",
            parameters={
                "model_path": "models/model.pkl",
                "data_path": "data/processed/titanic_processed.csv",
            },
        )

if __name__ == "__main__":
    run_pipeline()
```

```python
import random

# 初始化实验
wandb.init(
    project="titanic-classification",   # 项目名
    name="rf_experiment_v1",             # 运行名称
    config={                             # 超参数配置
        "n_estimators": 100,
        "max_depth": 10,
        "learning_rate": 0.01,
        "batch_size": 32,
        "epochs": 50,
    },
    tags=["baseline", "randomforest"],   # 标签
    notes="Baseline RandomForest模型",    # 备注
)

# 获取配置
config = wandb.config

# 训练过程中记录指标
for epoch in range(config.epochs):
    # 模拟训练
    train_loss = 1.0 / (epoch + 1) + random.random() * 0.1
    val_loss = train_loss + random.random() * 0.05
    train_acc = min(0.5 + epoch * 0.01, 0.99)
    val_acc = train_acc - random.random() * 0.05

    # 记录指标（每次调用自动生成时序图表）
    wandb.log({
        "train/loss": train_loss,
        "val/loss": val_loss,
        "train/accuracy": train_acc,
        "val/accuracy": val_acc,
        "epoch": epoch,
    })

# 保存文件
wandb.save("confusion_matrix.png")

# 保存模型
artifact = wandb.Artifact("model", type="model")
artifact.add_file("model.pkl")
wandb.log_artifact(artifact)

# 结束运行
wandb.finish()
```

#### 实验对比（控制变量法）

```
设计对比实验的核心原则：每次只改一个变量

示例：优化RandomForest模型

实验1 (Baseline):
  n_estimators=100, max_depth=None, min_samples_split=2
  结果: accuracy=0.82

实验2 (调n_estimators):
  n_estimators=200, max_depth=None, min_samples_split=2  ← 只改这个
  结果: accuracy=0.84  → n_estimators增加有效

实验3 (调max_depth):
```

```python
# reproducibility.py - 可复现性保障清单

import random
import numpy as np
import torch
import os

def set_seed(seed=42):
    """固定所有随机种子"""
    # Python内置随机
    random.seed(seed)

    # NumPy随机
    np.random.seed(seed)

    # PyTorch随机
    torch.manual_seed(seed)
    torch.cuda.manual_seed_all(seed)
    torch.backends.cudnn.deterministic = True
    torch.backends.cudnn.benchmark = False

    # 环境变量
    os.environ['PYTHONHASHSEED'] = str(seed)

    print(f"所有随机种子设为: {seed}")

# 记录完整配置
def log_full_config(mlflow, config):
    """记录完整配置确保可复现"""
    # 记录所有超参数
    mlflow.log_params(dict(config))

    # 记录环境信息
    import sys
    import platform
    mlflow.set_tag("python_version", sys.version)
    mlflow.set_tag("platform", platform.platform())

    # 记录依赖版本
    import pkg_resources
    requirements = [f"{d.key}=={d.version}" for d in pkg_resources.working_set]
    with open("requirements_frozen.txt", "w") as f:
        f.write("\n".join(requirements))
    mlflow.log_artifact("requirements_frozen.txt")

    # 记录Git信息
    import subprocess
    try:
        git_hash = subprocess.check_output(["git", "rev-parse", "HEAD"]).decode().strip()
```

#### 训练脚本集成MLflow

```python
# src/train.py
import os
import mlflow
import mlflow.pytorch
import hydra
from omegaconf import DictConfig, OmegaConf
import torch
from transformers import AutoModelForSequenceClassification, AutoTokenizer, Trainer, TrainingArguments
from sklearn.metrics import accuracy_score, f1_score, precision_score, recall_score
from dotenv import load_dotenv

load_dotenv()

def compute_metrics(eval_pred):
    logits, labels = eval_pred
    predictions = logits.argmax(axis=-1)
    return {
        "accuracy": accuracy_score(labels, predictions),
        "f1": f1_score(labels, predictions, average="weighted"),
        "precision": precision_score(labels, predictions, average="weighted"),
        "recall": recall_score(labels, predictions, average="weighted"),
    }

@hydra.main(config_path="../configs", config_name="config", version_base="1.3")
def main(cfg: DictConfig):
    # 设置随机种子
    torch.manual_seed(cfg.seed)

    # MLflow设置
    mlflow.set_tracking_uri(os.getenv("MLFLOW_TRACKING_URI", "http://localhost:5000"))
    mlflow.set_experiment(cfg.experiment_name)

    with mlflow.start_run(run_name=cfg.run_name):
        # 记录完整配置
        mlflow.log_params(OmegaConf.to_container(cfg, resolve=True))
        config_str = OmegaConf.to_yaml(cfg)
        with open("config_used.yaml", "w") as f:
            f.write(config_str)
        mlflow.log_artifact("config_used.yaml")

        # 加载模型和tokenizer
        tokenizer = AutoTokenizer.from_pretrained(cfg.model.name)
        model = AutoModelForSequenceClassification.from_pretrained(
            cfg.model.name,
            num_labels=cfg.model.num_labels,
        )

        # 训练参数
        training_args = TrainingArguments(
            output_dir=cfg.training.output_dir,
            num_train_epochs=cfg.training.epochs,
            per_device_train_batch_size=cfg.training.batch_size,
            learning_rate=cfg.training.learning_rate,
            weight_decay=cfg.training.weight_decay,
            evaluation_strategy="epoch",
            save_strategy="epoch",
            load_best_model_at_end=True,
            metric_for_best_model="accuracy",
        )

        # 数据加载（略）
        # train_dataset, eval_dataset = load_data(cfg, tokenizer)

        # 训练
        trainer = Trainer(
            model=model,
            args=training_args,
            train_dataset=train_dataset,
            eval_dataset=eval_dataset,
            compute_metrics=compute_metrics,
        )

        train_result = trainer.train()

        # 记录训练指标
        mlflow.log_metric("train_loss", train_result.training_loss)
        mlflow.log_metric("train_runtime", train_result.metrics["train_runtime"])

        # 评估
        eval_result = trainer.evaluate()
        for key, value in eval_result.items():
            mlflow.log_metric(f"eval_{key}", value)

        # 注册模型
        if eval_result["eval_accuracy"] >= cfg.registration.min_accuracy:
            mlflow.pytorch.log_model(
                model,
                "model",
                registered_model_name=cfg.registration.model_name,
            )
            print(f"模型注册成功: {cfg.registration.model_name}")
        else:
            print(f"精度{eval_result['eval_accuracy']:.4f}未达到阈值{cfg.registration.min_accuracy}")

        # 标签
        mlflow.set_tag("model_type", cfg.model.name)
        mlflow.set_tag("dataset", cfg.data.name)

if __name__ == "__main__":
    main()
```

### 题目

1. **MLflow的四个核心组件分别是什么？各自的作用是什么？**

2. **Model Registry中Staging和Production阶段分别表示什么？什么条件下可以转换？**

3. **W&B Sweeps支持哪些超参数搜索方法？各自的特点是什么？**

4. **Hydra配置覆盖的语法是什么？如何切换配置组？**

5. **如何保障ML实验的可复现性？需要记录哪些信息？**

### 参考答案

<details>
<summary>点击展开答案</summary>

1. **MLflow四个核心组件**:
   - **Tracking**: 记录实验参数、指标和产物
   - **Projects**: 打包ML代码，支持可复现运行
   - **Models**: 统一的模型打包格式，支持多种部署方式
   - **Model Registry**: 模型版本管理和阶段管理（Staging/Production）

2. **Staging**: 模型正在测试验证中，尚未部署到生产环境。条件：通过基本的离线评估（accuracy达到阈值）。
   **Production**: 模型已通过验证，正在生产环境使用。条件：通过A/B测试或其他在线验证。
   转换时可以设置archive_existing_versions=True自动归档旧版本。

3. **三种搜索方法**:
   - **grid**: 网格搜索，穷举所有参数组合，适合参数空间小的情况
   - **random**: 随机搜索，随机采样参数，适合参数空间大的情况
   - **bayes**: 贝叶斯优化，根据历史结果智能选择下一组参数，效率最高

4. **语法**: `python train.py key1=value1 key2=value2`
   - 覆盖参数: `python train.py model.lr=0.001 model.layers=6`
   - 切换配置组: `python train.py model=xgboost`（切换到configs/model/xgboost.yaml）
   - 多层覆盖: `python train.py model=xgboost model.n_estimators=500`

5. **可复现性保障清单**:
   - 固定所有随机种子（Python/NumPy/PyTorch）
   - 记录完整超参数配置
   - 记录数据版本（DVC hash）
   - 记录代码版本（Git commit hash）
   - 记录依赖版本（pip freeze > requirements.txt）
   - 记录环境信息（Python版本、操作系统、GPU型号）
   - 使用容器化（Docker）固定运行环境

## 七、Java开发者提示

> 帮助有Java背景的开发者理解ML实验管理概念

| ML实验管理概念 | Java类比 | 说明 |
|--------------|---------|------|
| MLflow Tracking | Log4J/SLF4J日志 | MLflow记录实验过程，类似日志记录程序运行 |
| MLflow Experiment | Maven Module | 每个Experiment是一组相关实验，类似Maven Module |
| MLflow Run | 一次JUnit测试运行 | 每次训练就是一个Run，类似一次测试执行 |
| MLflow Parameters | application.yml配置 | 超参数类似应用的配置项 |
| MLflow Metrics | JMeter测试报告 | 实验指标类似性能测试的结果数据 |
| MLflow Artifacts | Maven构建产物(jar) | 模型文件和图表类似构建产物 |
| Model Registry | Nexus/Artifactory制品库 | 模型注册中心类似Maven仓库 |
| Model Staging | Staging环境 | 模型先在Staging验证，类似代码先部署Staging环境 |
| Model Production | Production环境 | 通过验证的模型上生产，同代码部署生产 |
| W&B Sweeps | JUnit参数化测试 | 超参数搜索类似用不同参数跑同一测试 |
| Hydra配置 | Spring Profiles | Hydra的配置组切换类似Spring的profile(dev/prod) |
| OmegaConf | Jackson/YAML解析 | OmegaConf操作配置类似Jackson处理JSON |

### 关键思维转换

1. **实验即代码**: ML实验需要像代码一样被版本管理和追踪
2. **指标即日志**: 训练指标就是ML应用的"日志"，需要集中存储和查询
3. **模型即制品**: 模型就像jar包，需要制品仓库管理版本和发布流程
4. **配置即约束**: 训练配置像Spring配置一样，需要分层管理、环境隔离
5. **可复现即可调试**: 能复现的实验才能调试，就像有日志才能排查问题
