## 第 9 月：MLOps 全流程

### 第 25 周：数据工程与特征管理

#### 周目标

- 掌握 ML 数据管线的设计与实现
- 理解特征存储的概念和使用

#### 每日任务

| 天 | 任务 | 产出 |
|----|------|------|
| Day 1 | 数据管线设计：数据采集 → 清洗 → 转换 → 特征计算 → 存储，批处理 vs 流处理 | 数据管线架构图 |
| Day 2 | 数据版本管理：DVC（Data Version Control）安装使用、数据集版本追踪、与 Git 集成 | DVC 管线脚本 |
| Day 3 | 数据质量监控：数据分布检测、缺失值监控、异常值检测、Schema 验证（Great Expectations） | 数据质量检查脚本 |
| Day 4 | 特征存储（Feature Store）：概念理解、Feast / Hopsworks 安装使用、离线/在线特征 | Feature Store Demo |
| Day 5 | 特征工程自动化：自动特征生成（Featuretools）、特征选择流水线、特征重要性分析 | 自动特征工程 Pipeline |
| Day 6 | 数据标注：主动学习（Active Learning）、标注工具（Label Studio）、标注质量控制 | 标注工作流 |
| Day 7 | 实战：构建一个完整的数据处理管线（ETL → 特征计算 → 存储 → 版本管理） | 数据工程 Pipeline |

#### 验收标准

- [ ] 能用 DVC 管理数据集版本
- [ ] 理解 Feature Store 的概念和使用场景
- [ ] 能构建自动化的数据质量检查

适合人群：希望深入 LLM 应用开发

**项目概述：** 构建一个面向企业的智能知识库系统，支持多格式文档问答、权限控制、评估体系。

**第 29 周：需求分析与架构设计**

| 天 | 任务 |
|----|------|

| Day 3-4 | 架构设计：技术选型、系统架构图、数据流设计、API 设计 |
| Day 5-7 | 原型开发：最小可用版本（单文档上传 → 切分 → 检索 → 问答） |

**第 30 周：核心功能开发**

| 天 | 任务 |
|----|------|
| Day 1-2 | 多格式文档解析引擎（PDF/Word/Excel/Markdown/HTML）、表格提取、OCR 集成 |

**第 31 周：高级功能开发**

| 天 | 任务 |

#### 方向 C：模型微调平台

适合人群：希望深入模型训练和基础设施

**项目概述：** 构建一个自动化的模型微调平台，支持数据管理、训练配置、评估和部署。

**核心功能模块：**

- 数据管理：数据上传、格式转换、质量评估、自动清洗
- 训练管理：训练配置（LoRA 参数/数据集/基座模型选择）、GPU 资源调度、训练监控
- 评估体系：自动评估基准、人工评估界面、A/B 对比
- 模型部署：一键部署推理服务、模型版本管理、灰度发布
- Web 管理界面：训练仪表盘、评估报告、资源监控

#### 方向 D：Java + AI 混合架构

适合人群：希望结合 Java 优势做企业级 AI 应用

**项目概述：** 用 Java 做业务后端 + Python 做模型服务，构建完整的企业级 AI 应用。

**核心功能模块：**

- Java 后端（Spring Boot + Spring AI / LangChain4j）
- Python 模型服务（FastAPI + vLLM/TGI）
- gRPC/REST 通信层
- 业务逻辑层（用户管理、权限、审计、计费）
- 前端界面（React/Vue）
