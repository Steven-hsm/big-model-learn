# 第三阶段：LLM 与大模型工程（第 7-9 月）

> 阶段目标：掌握大语言模型的核心技术栈，能独立构建 RAG 系统、微调模型、开发 AI Agent、部署模型服务
> 阶段产出：5 个大模型相关项目（RAG 系统 + 微调项目 + AI Agent + Multi-Agent + 模型部署）

---

## 第 6 月：LLM 核心技术与 RAG

### 第 17 周：大语言模型基础

#### 周目标

- 理解大语言模型的架构演进和工作原理
- 掌握 Prompt Engineering 技术
- 能使用 OpenAI / Claude API 进行开发

#### 每日任务

| 天 | 任务 | 产出 |
|----|------|------|
| Day 1 | LLM 架构演进：GPT-1/2/3/4、BERT、LLaMA、Mistral、Qwen、DeepSeek，理解 Scaling Law | 架构对比表 |
| Day 2 | Tokenizer 深入：BPE、SentencePiece、tiktoken、Tokenizer 对模型效果的影响 | Tokenizer 对比实验 |
| Day 3 | Prompt Engineering 基础：系统提示、角色设定、Few-shot、Zero-shot、格式化输出 | Prompt 模板库（10+ 模板） |
| Day 4 | Prompt Engineering 进阶：Chain-of-Thought（CoT）、Tree-of-Thought（ToT）、Self-Consistency、ReAct | CoT/ToT 对比实验 |
| Day 5 | OpenAI API 开发：ChatCompletion、Function Calling、Streaming、错误处理、速率限制 | OpenAI API 封装工具类 |
| Day 6 | Claude API / Anthropic SDK：Messages API、Tool Use、系统提示、多轮对话、缓存（Prompt Caching） | Claude API 封装工具类 |
| Day 7 | 实战：构建一个多功能对话助手（支持不同角色、格式化输出、错误处理） | 练习项目：对话助手 |

#### 验收标准

- [ ] 理解主流 LLM 架构的区别（Decoder-Only vs Encoder-Decoder vs Encoder-Only）
- [ ] 能设计高质量的 Prompt 并理解 CoT 等技术
- [ ] 能熟练使用 OpenAI / Claude API 开发应用
