### Day 1: LLM评估方法

#### 3.1.1 自动评估指标

**BLEU (Bilingual Evaluation Understudy)**

用于机器翻译评估，衡量生成文本与参考文本的n-gram精确率。

```
BLEU = BP × exp(Σ wn × log pn)

其中：
  pn = n-gram精确率（1-gram, 2-gram, 3-gram, 4-gram）
  wn = 各n-gram的权重（通常均匀 1/4）
  BP = 简短惩罚因子 = min(1, exp(1 - reference_len/output_len))

示例：
  参考：猫坐在垫子上
  生成：猫坐在垫子上
  BLEU-4 = 1.0（完全匹配）

  参考：猫坐在垫子上
  生成：一只猫在垫子上睡觉
  BLEU-4 = 0.35（部分匹配）
```

```python
from nltk.translate.bleu_score import sentence_bleu

reference = [["猫", "坐", "在", "垫子", "上"]]
candidate = ["猫", "坐", "在", "垫子", "上"]
score = sentence_bleu(reference, candidate)
print(f"BLEU Score: {score:.4f}")
```

**ROUGE (Recall-Oriented Understudy for Gisting Evaluation)**

用于文本摘要评估，衡量召回率。

```
ROUGE-1 = 重叠的unigram数 / 参考文本的unigram总数
ROUGE-2 = 重叠的bigram数 / 参考文本的bigram总数
ROUGE-L = 最长公共子序列(LCS)长度 / 参考文本长度

示例：
  参考：人工智能改变了世界的生活方式
  生成：人工智能深刻影响了人们的生活方式
  ROUGE-1: 重叠词={人工智能,了,的,生活,方式} = 5/8 = 0.625
```

```python
from rouge_score import rouge_scorer

scorer = rouge_scorer.RougeScorer(['rouge1', 'rouge2', 'rougeL'], use_stemmer=True)
scores = scorer.score(
    "人工智能改变了世界的生活方式",
    "人工智能深刻影响了人们的生活方式"
)
for metric, score in scores.items():
    print(f"{metric}: Precision={score.precision:.4f}, Recall={score.recall:.4f}, F1={score.fmeasure:.4f}")
```

#### 3.1.2 LLM-as-Judge

用强模型评估弱模型的输出。

```python
class LLMJudge:
    """LLM-as-Judge评估器"""

    def __init__(self, client, judge_model="gpt-4o"):
        self.client = client
        self.judge_model = judge_model

    def evaluate_pair(self, question, answer_a, answer_b, criteria=None):
        """成对比较评估（Pairwise Comparison）"""
        if criteria is None:
            criteria = "准确性、完整性、清晰度、相关性"

        prompt = f"""你是一个公正的评估者。请评估以下两个回答的质量。

问题：{question}

回答A：
{answer_a}

回答B：
{answer_b}

评估标准：{criteria}

请从以下选项中选择：
A: 回答A更好
B: 回答B更好
C: 两者相当
D: 两者都不好

请先分析每个回答的优缺点，然后给出你的选择和理由。"""

        response = self.client.chat.completions.create(
            model=self.judge_model,
            messages=[{"role": "user", "content": prompt}],
            temperature=0,
        )
        return response.choices[0].message.content

    def evaluate_single(self, question, answer, rubric=None):
        """单一回答评分（Point-wise Scoring）"""
        if rubric is None:
            rubric = """
1分：完全无关或错误
2分：部分相关但有明显错误
3分：基本正确但不完整
4分：正确且较完整
5分：正确、完整、清晰、有深度"""

        prompt = f"""你是一个公正的评估者。请评估以下回答的质量。

问题：{question}
回答：{answer}

评分标准：
{rubric}

请给出评分(1-5)和详细理由。"""

        response = self.client.chat.completions.create(
            model=self.judge_model,
            messages=[{"role": "user", "content": prompt}],
            temperature=0,
        )
        return response.choices[0].message.content

    def batch_evaluate(self, questions, answers, references=None):
        """批量评估"""
        results = []
        for i, (q, a) in enumerate(zip(questions, answers)):
            ref_text = f"\n参考答案：{references[i]}" if references else ""
            result = self.evaluate_single(q, a)
            results.append({
                "question": q,
                "answer": a,
                "evaluation": result,
            })
        return results
```

### Day 3: 幻觉检测与缓解

#### 3.3.1 幻觉类型

```
1. 事实性幻觉 (Factual Hallucination)
   - 编造不存在的事实
   例："Python 4.0于2024年发布"（Python没有4.0版本）

2. 忠实性幻觉 (Faithfulness Hallucination)
   - 生成内容与给定上下文矛盾
   例：上下文说"A公司成立于2000年"，模型回答"A公司成立于1995年"

3. 推理幻觉
   - 推理过程中的逻辑错误
   例：数学计算中的错误步骤
```

#### 3.3.2 检测方法

**Self-Check（模型自检）**

```python
class SelfCheckHallucinationDetector:
    """Self-Check幻觉检测"""

    def __init__(self, llm_client):
        self.llm = llm_client

    def check_claim(self, claim, context=None):
        """检查单个声明是否有幻觉"""
        if context:
            prompt = f"""请验证以下声明是否与给定上下文一致。

上下文：{context}

声明：{claim}

请分析：
1. 该声明是否可以从上下文中推导出来？
2. 是否有任何与上下文矛盾的部分？
3. 结论：一致/不一致/无法判断

请详细说明理由。"""
        else:
            prompt = f"""请评估以下声明的可信度。

声明：{claim}

请分析：
1. 该声明是否符合常识？
2. 是否有任何可疑的细节？
3. 可信度：高/中/低

请详细说明理由。"""

        response = self.llm.chat.completions.create(
            model="gpt-4o",
            messages=[{"role": "user", "content": prompt}],
            temperature=0,
        )
        return response.choices[0].message.content

    def multi_turn_verify(self, answer, num_questions=3):
        """多轮验证：生成问题来检验答案"""
        # Step 1: 基于答案生成验证问题
        question_prompt = f"""基于以下回答，生成{num_questions}个可以验证其准确性的问题。
回答：{answer}

请生成具体、可验证的问题。"""

        questions_response = self.llm.chat.completions.create(
            model="gpt-4o",
            messages=[{"role": "user", "content": question_prompt}],
            temperature=0.3,
        )
        questions = questions_response.choices[0].message.content

        # Step 2: 用LLM独立回答验证问题
        verify_prompt = f"""请独立回答以下问题（不参考原回答）：
{questions}

逐题回答。"""

        verify_response = self.llm.chat.completions.create(
            model="gpt-4o",
            messages=[{"role": "user", "content": verify_prompt}],
            temperature=0.3,
        )
        independent_answers = verify_response.choices[0].message.content

        # Step 3: 对比原回答和独立回答
        compare_prompt = f"""对比原回答和独立验证回答，检测是否存在矛盾。

原回答：{answer}
独立验证回答：{independent_answers}

是否存在矛盾或不一致？详细分析。"""

        compare_response = self.llm.chat.completions.create(
            model="gpt-4o",
            messages=[{"role": "user", "content": compare_prompt}],
            temperature=0,
        )
        return compare_response.choices[0].message.content

    def consistency_check(self, question, num_samples=3):
        """一致性检查：多次生成答案，检查是否一致"""
        answers = []
        for i in range(num_samples):
            response = self.llm.chat.completions.create(
                model="gpt-4o",
                messages=[{"role": "user", "content": question}],
                temperature=0.7,  # 较高温度产生多样性
            )
            answers.append(response.choices[0].message.content)

        # 让LLM判断一致性
        consistency_prompt = f"""以下是同一个问题的{num_samples}次回答，请判断它们是否一致。

问题：{question}

回答1：{answers[0]}
回答2：{answers[1]}
回答3：{answers[2]}

一致性分析（核心结论是否相同）："""

        response = self.llm.chat.completions.create(
            model="gpt-4o",
            messages=[{"role": "user", "content": consistency_prompt}],
            temperature=0,
        )
        return {
            "answers": answers,
            "consistency_analysis": response.choices[0].message.content,
        }
```

#### 3.3.3 缓解策略

```python
class HallucinationMitigator:
    """幻觉缓解策略集合"""

    def __init__(self, llm_client):
        self.llm = llm_client

    def generate_with_citation(self, question, context):
        """策略1: RAG提供事实依据 + 引用溯源"""
        prompt = f"""基于以下上下文回答问题。每个事实声明都必须引用具体的上下文内容。

上下文：
{context}

问题：{question}

要求：
1. 只基于上下文中的信息回答
2. 对每个声明标注来源，如[来源1]
3. 如果上下文中没有相关信息，明确说明"""

        response = self.llm.chat.completions.create(
            model="gpt-4o",
            messages=[{"role": "user", "content": prompt}],
            temperature=0.1,  # 低temperature减少创造性
        )
        return response.choices[0].message.content

    def generate_with_cot(self, question):
        """策略2: CoT让模型展示推理过程"""
        prompt = f"""请回答以下问题，并展示完整的推理过程。
如果不确定，请明确说明哪里不确定。

问题：{question}

推理过程："""

        response = self.llm.chat.completions.create(
            model="gpt-4o",
            messages=[{"role": "user", "content": prompt}],
            temperature=0.3,
        )
        return response.choices[0].message.content

    def generate_with_uncertainty(self, question):
        """策略3: 让模型表达不确定性"""
        prompt = f"""回答以下问题。如果你对答案不确定，请明确说"我不确定"并解释原因。
宁可说"我不确定"，也不要编造答案。

问题：{question}"""

        response = self.llm.chat.completions.create(
            model="gpt-4o",
            messages=[{"role": "user", "content": prompt}],
            temperature=0.1,
        )
        return response.choices[0].message.content
```

### Day 4: RLHF原理

#### 3.4.1 三步流程

```
Step 1: SFT (Supervised Fine-Tuning)
  ┌─────────────────────────────┐
  │  预训练模型 + 指令数据       │
  │  → 监督微调得到SFT模型       │
  └─────────────────────────────┘

Step 2: 训练Reward Model (RM)
  ┌─────────────────────────────┐
  │  SFT模型对同一问题生成多个回答  │
  │  → 人类标注偏好排序            │
  │  → 训练打分模型(RM)           │
  │  RM: (question, answer) → score │
  └─────────────────────────────┘

Step 3: PPO强化学习优化
  ┌─────────────────────────────┐
  │  SFT模型生成回答 → RM打分     │
  │  → PPO更新SFT模型策略         │
  │  → KL散度约束防止偏离太远      │
  │  → 得到对齐后的模型            │
  └─────────────────────────────┘
```

#### 3.4.2 Reward Model训练

```
偏好数据格式：
{
  "prompt": "解释什么是递归",
  "chosen": "递归是函数调用自身的编程技术...",     # 人类偏好的回答
  "rejected": "递归就是循环...",                    # 人类不喜欢的回答
}

RM训练目标：
对偏好数据对(chosen, rejected)，训练RM使：
  score(chosen) > score(rejected)

使用Bradley-Terry模型：
Loss = -log(σ(score(chosen) - score(rejected)))

σ是sigmoid函数
```

#### 3.4.3 PPO优化

```
PPO目标函数：

L = E[r(x, y)] - β × KL[π_θ(y|x) || π_ref(y|x)]

其中：
  r(x, y): Reward Model对prompt x、回答 y 的评分
  π_θ: 当前策略模型
  π_ref: 参考模型（SFT模型，固定不动）
  β: KL惩罚系数
  KL[·||·]: KL散度，衡量两个分布的差异

为什么需要KL约束？
  如果没有KL约束，策略模型可能学会"欺骗"RM
  （生成RM给高分但实际不好的回答），这叫 Reward Hacking
  KL约束确保优化后的模型不会偏离原始SFT模型太远
```

```
PPO训练流程：

1. 从prompt数据集中采样一批prompt
2. 当前策略模型π_θ对每个prompt生成回答y
3. RM对每个(prompt, y)对计算奖励r
4. 参考模型π_ref计算KL惩罚
5. 计算PPO目标 L = r - β×KL
6. 用PPO算法更新策略模型π_θ
7. 重复1-6
```

### Day 5: DPO原理

#### 3.5.1 核心思想

```
DPO (Direct Preference Optimization)
核心创新：把RLHF的3步合并为1步，直接用偏好数据训练

RLHF: SFT → 训练RM → PPO强化学习
DPO:  SFT → 直接用偏好数据优化（不需要RM，不需要PPO）

关键洞察：
  最优策略可以用偏好数据的似然比直接表达，
  跳过了显式训练RM的步骤。
```

#### 3.5.2 DPO损失函数

```
L_DPO = -E[log σ(β × (log π_θ(y_w|x)/π_ref(y_w|x) - log π_θ(y_l|x)/π_ref(y_l|x)))]

其中：
  y_w: 偏好的回答 (winner)
  y_l: 不偏好的回答 (loser)
  π_θ: 当前策略模型
  π_ref: 参考模型
  β: 温度参数（控制偏好强度）
  σ: sigmoid函数

直觉理解：
  增大π_θ生成偏好回答y_w的概率
  减小π_θ生成不偏好回答y_l的概率
  相对于参考模型π_ref的比值
```

#### 3.5.3 DPO训练代码

```python
from trl import DPOTrainer, DPOConfig
from transformers import AutoModelForCausalLM, AutoTokenizer
from datasets import load_dataset

# 加载模型
model_name = "./sft_model"  # 先SFT微调过的模型

tokenizer = AutoTokenizer.from_pretrained(model_name)
tokenizer.pad_token = tokenizer.eos_token

# 参考模型（冻结不动）
model_ref = AutoModelForCausalLM.from_pretrained(model_name)

# 加载偏好数据
dataset = load_dataset("json", data_files="preference_data.jsonl")
# 数据格式: {"prompt": "...", "chosen": "...", "rejected": "..."}

# DPO训练配置
training_args = DPOConfig(
    output_dir="./dpo_output",
    num_train_epochs=1,
    per_device_train_batch_size=4,
    learning_rate=5e-5,
    beta=0.1,              # DPO温度参数
    max_length=512,
    max_prompt_length=256,
    remove_unused_columns=False,
)

# 创建DPO Trainer
trainer = DPOTrainer(
    model=model,
    ref_model=model_ref,
    args=training_args,
```

```python
class ContentFilter:
    """内容过滤器"""

    def __init__(self, sensitive_words_path="sensitive_words.txt"):
        self.sensitive_words = self._load_sensitive_words(sensitive_words_path)

    def _load_sensitive_words(self, path):
        with open(path, 'r', encoding='utf-8') as f:
            return [line.strip() for line in f if line.strip()]

    def filter_text(self, text):
        """检查文本是否包含敏感内容"""
        flagged = []
        for word in self.sensitive_words:
            if word in text:
                flagged.append(word)
        return {
            "is_safe": len(flagged) == 0,
            "flagged_words": flagged,
        }

    def llm_based_filter(self, text, llm_client):
        """使用LLM判断内容安全性"""
        prompt = f"""请判断以下内容是否安全、合规。

内容：{text}

请从以下维度评估：
1. 是否包含有害内容（暴力/歧视/违法）
2. 是否包含隐私信息（姓名/电话/身份证）
3. 是否包含不当建议
4. 安全等级：安全/需审查/不安全"""

        response = llm_client.chat.completions.create(
            model="gpt-4o",
            messages=[{"role": "user", "content": prompt}],
            temperature=0,
        )
        return response.choices[0].message.content
```

```python
class JailbreakDetector:
    """越狱攻击检测"""

    KNOWN_PATTERNS = [
        "ignore previous instructions",
        "forget all rules",
        "you are now DAN",
        "pretend you are",
        "jailbreak",
        "system prompt",
        "无视之前的指令",
        "忽略所有规则",
        "你现在没有任何限制",
    ]

    def detect(self, user_input):
        """检测是否可能为越狱攻击"""
        input_lower = user_input.lower()

        # 规则匹配
        matched_patterns = []
        for pattern in self.KNOWN_PATTERNS:
            if pattern in input_lower:
                matched_patterns.append(pattern)

        # 特征检测
        suspicious_features = []
        if len(user_input) > 2000:
            suspicious_features.append("超长输入")
        if user_input.count("\n") > 20:
            suspicious_features.append("大量换行")
        if "###" in user_input or "====" in user_input:
            suspicious_features.append("含特殊分隔符")

        is_jailbreak = len(matched_patterns) > 0 or len(suspicious_features) >= 2

        return {
            "is_jailbreak": is_jailbreak,
            "matched_patterns": matched_patterns,
            "suspicious_features": suspicious_features,
        }
```

## 六、自测题

### 题目

1. **BLEU和ROUGE的区别？**

<details>
<summary>参考答案</summary>

BLEU关注精确率（Precision）：生成文本中有多少n-gram出现在参考文本中。BLEU越高说明生成的文本越"精确"地匹配参考文本，适用于机器翻译。ROUGE关注召回率（Recall）：参考文本中有多少n-gram出现在生成文本中。ROUGE越高说明生成的文本"覆盖"了参考文本的更多内容，适用于文本摘要。简单说：BLEU侧重"生成的都是对的"，ROUGE侧重"该有的都有"。
</details>

2. **LLM-as-Judge的原理和局限性？**

<details>
<summary>参考答案</summary>

原理：用一个更强大的LLM（如GPT-4）作为评判者，评估其他模型的输出质量。评估方式包括成对比较（A vs B哪个更好）和单点评分（1-5分）。通过精心设计的评估Prompt，让Judge模型从准确性、完整性、清晰度等维度进行评估。局限性：(1) Judge模型本身可能有偏见（如偏向更长的回答、偏向自己风格的回答）；(2) 评估结果可能不稳定，同一输入不同次评估结果不同；(3) 无法完全替代人工评估，特别是细微的质量差异；(4) 评估成本较高（需要调用强模型的API）。
</details>

3. **RLHF的三步流程？**

<details>
<summary>参考答案</summary>

(1) SFT监督微调：用指令数据对预训练模型进行监督微调，得到SFT模型，使模型学会遵循指令。(2) 训练Reward Model：SFT模型对同一问题生成多个回答，人类标注偏好排序（哪个回答更好），用这些偏好数据训练一个打分模型（RM），输入(prompt, answer)，输出一个标量分数。(3) PPO强化学习：SFT模型（策略模型）生成回答→RM打分→用PPO算法更新策略模型→用KL散度约束防止模型偏离参考模型太远。最终得到对齐后的模型。
</details>

4. **DPO相比RLHF的优势？**

<details>
<summary>参考答案</summary>

DPO的核心优势是简化了训练流程：(1) 不需要训练Reward Model，直接用偏好数据训练策略模型，从3步变2步；(2) 不需要PPO算法，避免了PPO调参困难、训练不稳定的问题；(3) 计算资源需求更低，RLHF需要同时维护4个模型（策略模型、参考模型、RM、Value模型），DPO只需要2个（策略模型、参考模型）；(4) 实现更简单，代码更少，更容易复现。效果方面，研究表明DPO在多数任务上达到与RLHF相当甚至更好的效果。
</details>

5. **模型幻觉的常见缓解策略？**

<details>
<summary>参考答案</summary>

(1) RAG提供事实依据：让模型基于检索到的文档回答，而不是依赖参数化记忆；(2) Chain-of-Thought：让模型展示推理过程，错误更容易被发现和纠正；(3) 降低temperature：减少采样的随机性，让模型更倾向于高概率（更确定）的输出；(4) 自我一致性（Self-Consistency）：多次采样取投票最多的答案，不一致的答案可能是幻觉；(5) 引用溯源：要求模型标注信息来源，无法标注来源的声明可能是幻觉；(6) 让模型表达不确定性：明确告诉模型"如果不确定就说不知道"。
</details>
