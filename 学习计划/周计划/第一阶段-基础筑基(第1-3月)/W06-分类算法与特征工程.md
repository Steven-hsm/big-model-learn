### Day 1（周一）：决策树

#### 1.1 信息熵与划分标准

```
信息熵（衡量不确定性）：
  H(S) = -Σ pᵢ × log₂(pᵢ)
  熵越高 → 数据越混乱 → 纯度越低

信息增益（ID3 用）：
  IG(S, A) = H(S) - Σ(|Sᵥ|/|S|) × H(Sᵥ)
  选信息增益最大的特征划分

基尼系数（CART 用，sklearn 默认）：
  Gini(S) = 1 - Σ pᵢ²
  计算比熵快（不需要 log），效果接近
```

#### 1.2 决策树构建过程

```
1. 计算所有特征的划分标准（基尼/信息增益）
2. 选择最优特征和分裂点
3. 将数据按分裂点分成子集
4. 对子集递归执行 1-3
5. 停止条件：节点纯度达标 / 达到最大深度 / 样本数太少
```

### Day 2（周二）：集成学习

#### 2.1 Bagging → 随机森林

```
核心思想：训练多个独立模型，投票/平均降低方差

随机森林：
1. 从训练集中有放回抽样生成 n 棵树的训练数据（Bootstrap）
2. 每棵树在每个节点随机选 √m 个特征（m 为总特征数）
3. 每棵树独立训练到最大深度（不剪枝）
4. 分类：多数投票 / 回归：取平均

为什么有效？
- 每棵树都有不同的"视角"（不同数据+不同特征）
- 组合后偏差不变但方差大幅降低
```

```python
from sklearn.ensemble import RandomForestClassifier

rf = RandomForestClassifier(
    n_estimators=100,    # 树的数量
    max_depth=10,        # 最大深度
    min_samples_leaf=5,
    n_jobs=-1,           # 并行训练
    random_state=42
)
rf.fit(X_train, y_train)

# OOB Score（袋外评估，不需要验证集）

print(f"OOB Score: {rf_oob.oob_score_:.4f}")
```

#### 2.2 Boosting → XGBoost / LightGBM

```
核心思想：串行训练，每个新模型纠正前一个模型的错误，降低偏差

AdaBoost：加大被错分样本的权重，下一棵树重点关注
Gradient Boosting：新树拟合上一轮的残差（负梯度）
XGBoost：在 Gradient Boosting 基础上加正则化、并行化、列采样
LightGBM：直方图加速、Leaf-wise 生长策略（更快）
```


### Day 3（周三）：SVM 支持向量机

#### 3.1 SVM 原理

```
最大间隔分类器：
  目标：找到一条决策边界，使离边界最近的点（支持向量）到边界的距离最大
  优化目标：min ½||w||²  s.t. yᵢ(w·xᵢ+b) ≥ 1

软间隔（允许一些误分类）：
  min ½||w||² + C × Σξᵢ
  C 越大 → 对误分类惩罚越大 → 越容易过拟合
  C 越小 → 容忍更多误分类 → 越容易欠拟合
```

#### 3.2 核函数

```
线性核：K(x, x') = x·x'         → 线性可分数据
RBF 核：K(x, x') = exp(-γ||x-x'||²)  → 最常用，能处理非线性
多项式核：K(x, x') = (x·x'+c)^d    → 特征交叉

γ 参数：控制 RBF 的"影响范围"
  γ 大 → 每个点影响范围小 → 决策边界复杂 → 过拟合
  γ 小 → 每个点影响范围大 → 决策边界平滑 → 欠拟合
```

```python
from sklearn.svm import SVC

# RBF 核 SVM
```

## 自测题

1. **信息熵和基尼系数的区别？为什么 sklearn 默认用基尼？**
   <details><summary>参考答案</summary>
   信息熵 H(S)=-Σpᵢlog(pᵢ)，基尼 Gini(S)=1-Σpᵢ²。基尼不需要计算对数，训练速度更快。效果上非常接近，基尼倾向于 isolating the most common class，熵倾向于产生更平衡的树。
   </details>

2. **Bagging 和 Boosting 的核心区别？分别解决什么问题？**
   <details><summary>参考答案</summary>
   Bagging：并行训练多个独立模型，降低方差。适合高方差模型（如不剪枝的决策树）。代表：随机森林。
   Boosting：串行训练，每个新模型纠正前一个错误，降低偏差。适合高偏差模型。代表：XGBoost/LightGBM。
   </details>

3. **SVM 的核函数作用？什么时候用 RBF？**
   <details><summary>参考答案</summary>
   核函数通过映射到高维空间使线性不可分的数据变得可分，而不需要显式计算高维映射（核技巧）。RBF 是最常用的默认选择，适合大多数非线性问题。线性核适合特征多但样本少的情况（文本分类），训练更快。
   </details>

4. **OneHotEncoder 和 LabelEncoder 分别适合什么场景？**
   <details><summary>参考答案</summary>
   LabelEncoder：有序类别（学历：高中/本科/硕士 → 0/1/2），数值大小有意义。OneHotEncoder：无序类别（颜色：红/绿/蓝 → [1,0,0]/[0,1,0]/[0,0,1]），避免引入虚假的顺序关系。高基数类别（如城市名）用 TargetEncoder。
   </details>

5. **处理类别不平衡的 3 种方法？**
   <details><summary>参考答案</summary>
   (1) 过采样 SMOTE：合成少数类样本，不丢失信息但可能过拟合。
   (2) 欠采样：删除多数类样本，简单但可能丢失有用信息。
   (3) 类权重 class_weight：调整损失函数权重，不改数据但可能影响概率校准。
   实践中通常组合使用，且应关注 F1/召回率而非准确率。
   </details>
