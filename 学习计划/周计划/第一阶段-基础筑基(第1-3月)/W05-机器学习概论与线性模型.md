### Day 1（周一）：机器学习概论

#### 1.1 机器学习三大类型

- **监督学习 Supervised Learning**：有标签数据，学习输入 X 到输出 Y 的映射
  - 回归 Regression：输出连续值（如房价预测、温度预测）
  - 分类 Classification：输出离散类别��如垃圾邮件检测、疾病诊断）
- **无监督学习 Unsupervised Learning**：无标签数据，发现数据内在结构
  - 聚类 Clustering：将数据分组（如用户分群）
  - 降维 Dimensionality Reduction：压缩特征（如 PCA）
- **强化学习 Reinforcement Learning**：通过与环境交互学习策略（了解即可）
  - Agent 在 Environment 中采取 Action，获得 Reward，优化 Policy

#### 1.2 数据集划分

```
全部数据 ──┬── 训练集 Training Set (60-70%)    → 训练模型参数
           ├── 验证集 Validation Set (15-20%)  → 调超参数、选择模型
           └── 测试集 Test Set (15-20%)        → 最终评估，只用一次
```

- 为什么需要验证集？训练集训练模型，验证集选择超参数，测试集给出无偏估计
- K-Fold 交叉验证：数据分 K 份，轮流用 1 份做验证、其余做训练，取平均

#### 1.3 偏差-方差权衡 Bias-Variance Tradeoff（核心概念）

```
总误差 = 偏差² + 方差 + 不可约误差

高偏差（欠拟合）：模型太简单，连训练集都拟合不好
  → 解决：增加特征、使用更复杂模型、减少正则化

高方差（过拟合）：模型太复杂，训练集拟合很好但测试集差
  → 解决：增加数据、正则化、降低模型复杂度、Early Stopping
```

**学习曲线分析**：画 train_loss 和 val_loss 随训练数据量/模型复杂度的变化曲线

#### 代码练习

```python
import matplotlib.pyplot as plt

# 模拟不同模型复杂度下的误差
complexity = np.arange(1, 20)

plt.xlabel('Model Complexity')
plt.ylabel('Error')
plt.title('Bias-Variance Tradeoff')
plt.legend()
plt.axvline(x=complexity[np.argmin(total_error)], color='gray', linestyle='--')
plt.show()
```

### Day 2（周二）：线性回归

#### 2.1 线性回归原理

假设函数：`h(x) = w₁x₁ + w₂x₂ + ... + wₙxₙ + b = W·X + b`

损失函数 MSE：`J(W, b) = (1/2m) × Σ(h(xᵢ) - yᵢ)²`

两种求解方法：
- **正规方程 Normal Equation**（解析解，直接算出最优 W）：
  `W = (X^T × X)^(-1) × X^T × y`
  - 优点：不需要选学习率，一步到位
  - 缺点：X^TX 求逆复杂度 O(n³)，特征多时很慢；X^TX 可能不可逆
- **梯度下降 Gradient Descent**（迭代优化）：
  `W = W - α × ∂J/∂W`，其中 `∂J/∂W = (1/m) × X^T × (X·W - y)`

#### 2.2 NumPy 实现

```python
import numpy as np

class LinearRegression:
    def __init__(self, lr=0.01, n_iters=1000):
        self.lr = lr
        self.n_iters = n_iters
        self.weights = None
        self.bias = None

    def fit(self, X, y):
        n_samples, n_features = X.shape
        self.weights = np.zeros(n_features)
        self.bias = 0

        for i in range(self.n_iters):
            # 前向传播
            y_pred = np.dot(X, self.weights) + self.bias
            # 计算梯度
            dw = (1 / n_samples) * np.dot(X.T, (y_pred - y))
            db = (1 / n_samples) * np.sum(y_pred - y)
            # 更新参数
            self.weights -= self.lr * dw
            self.bias -= self.lr * db

    def predict(self, X):
        return np.dot(X, self.weights) + self.bias
```

#### 2.3 sklearn 实现

```python
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error, r2_score

# 数据划分

# 训练

model.fit(X_train, y_train)

# 预测和评估

print(f"MSE: {mean_squared_error(y_test, y_pred):.4f}")
print(f"R²: {r2_score(y_test, y_pred):.4f}")
```

### Day 3（周三）：线性回归进阶 + 正则化

#### 3.1 多项式回归


- degree 越高模型越灵活，但容易过拟合
- 必须配合正则化使用

#### 3.2 正则化

```
Ridge (L2)：J_reg = J(W) + α × Σwᵢ²
  → 所有权重趋于小值，不会精确为 0
  → 适合特征都有用、存在共线性的场景

Lasso (L1)：J_reg = J(W) + α × Σ|wᵢ|
  → 部分权重精确为 0，自动做特征选择
  → 适合特征多但只有少部分有用的场景

ElasticNet：J_reg = J(W) + α₁ × Σ|wᵢ| + α₂ × Σwᵢ²
  → 结合 L1 和 L2 的优点
```

```python
from sklearn.linear_model import Ridge, Lasso, ElasticNet

# Ridge 回归
ridge = Ridge(alpha=1.0)   # alpha 越大正则化越强

# Lasso 回归
lasso = Lasso(alpha=0.1)   # 会将不重要的特征权重置为 0

# 对比不同 alpha 的影响
for alpha in [0.001, 0.01, 0.1, 1, 10]:
    ridge = Ridge(alpha=alpha)
    ridge.fit(X_train, y_train)
    print(f"alpha={alpha}, train_score={ridge.score(X_train, y_train):.4f}, "
          f"test_score={ridge.score(X_test, y_test):.4f}")
```

### Day 4（周四）：逻辑回归 + 模型评估

#### 4.1 逻辑回归原理

```
假设函数：h(x) = σ(W·X + b) = 1 / (1 + e^(-W·X+b))
  → 将线性输出映射到 [0, 1] 区间，表示属于正类的概率

损失函数（交叉熵）：
  J(W) = -(1/m) × Σ[yᵢ·log(h(xᵢ)) + (1-yᵢ)·log(1-h(xᵢ))]

多分类（Softmax）：
  P(class=k|x) = e^(Wk·x) / Σ(e^(Wj·x))
```

#### 4.2 混淆矩阵与评估指标

```
                  预测正   预测负
        实际正     TP       FN
        实际负     FP       TN

准确率 Accuracy  = (TP + TN) / Total
精确率 Precision = TP / (TP + FP)   → 预测为正的里面多少是对的
召回率 Recall    = TP / (TP + FN)   → 实际为正的里面多少被找到
F1 Score         = 2 × P × R / (P + R)  → 精确率和召回率的调和平均

ROC 曲线：横轴 FPR=FP/(FP+TN)，纵轴 TPR=Recall
AUC：ROC 曲线下面积，越接近 1 越好
```

```python
from sklearn.metrics import (confusion_matrix, classification_report,
                              roc_curve, auc, roc_auc_score)
import matplotlib.pyplot as plt

# 混淆矩阵
cm = confusion_matrix(y_test, y_pred)
print(classification_report(y_test, y_pred))

# ROC 曲线
y_prob = model.predict_proba(X_test)[:, 1]
fpr, tpr, thresholds = roc_curve(y_test, y_prob)
plt.plot(fpr, tpr, label=f'AUC={auc(fpr, tpr):.3f}')
plt.plot([0,1], [0,1], 'k--')
plt.xlabel('FPR'); plt.ylabel('TPR'); plt.title('ROC Curve')
plt.legend(); plt.show()
```

## 自测题

1. **过拟合和欠拟合分别怎么判断？怎么解决？**
   <details><summary>参考答案</summary>
   过拟合：训练集 loss 低、测试集 loss 高。解决：增加数据、正则化、降低模型复杂度、Dropout、Early Stopping。
   欠拟合：训练集和测试集 loss 都高。解决：增加特征、使用更复杂模型、减少正则化。
   </details>

2. **L1 和 L2 正则化的区别？为什么 L1 能做特征选择？**
   <details><summary>参考答案</summary>
   L2（Ridge）将权重压缩到接近 0 但不为 0，适合所有特征都有用的场景。L1（Lasso）能将部分权重精确置为 0，因为 L1 的约束区域是菱形，更容易在顶点（某些维度为 0）处与等高线相切。所以 L1 天然具有特征选择能力。
   </details>

3. **为什么分类问题不用 MSE 而用交叉熵损失？**
   <details><summary>参考答案</summary>
   两个原因：(1) MSE + Sigmoid 组合的梯度在 σ(z) 接近 0 或 1 时趋近于 0（梯度消失），学习慢。(2) 交叉熵的梯度 = ŷ - y，始终与误差成正比，学习效率更高。数学上，交叉熵是伯努利分布的最大似然估计的负对数。
   </details>

4. **交叉验证的作用？K 值怎么选？**
   <details><summary>参考答案</summary>
   交叉验证的作用：(1) 充分利用数据，避免单次划分的随机性影响。(2) 评估模型的泛化能力，检测过拟合。K 值一般选 5 或 10。K 太小评估偏差大（训练数据少），K 太大计算成本高且方差大（LOO）。分类问题用 StratifiedKFold 保持类别比例。
   </details>

5. **精确率和召回率哪个更重要？举例说明。**
   <details><summary>参考答案</summary>
   看具体场景：癌症筛查 → 召回率更重要（漏检代价大，宁可误报不能漏报）。垃圾邮件过滤 → 精确率更重要（把正常邮件判为垃圾邮件代价大）。搜索引擎 → 两者都重要，通常看 F1 或 NDCG。
   </details>
