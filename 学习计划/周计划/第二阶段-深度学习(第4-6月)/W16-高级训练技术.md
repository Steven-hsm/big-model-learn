### Day 1: 学习率调度

#### 1. Cosine Annealing（余弦退火）

```
lr_t = lr_min + 0.5 * (lr_max - lr_min) * (1 + cos(πt/T))
```

特点：
- 学习率按余弦曲线从最大值平滑下降到最小值
- 训练初期大学习率快速收敛，后期小学习率精细调整
- 比StepLR更平滑，不会突然下降

```python
from torch.optim.lr_scheduler import CosineAnnealingLR

optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3)
scheduler = CosineAnnealingLR(optimizer, T_max=100, eta_min=1e-6)

for epoch in range(100):
    train(...)
    scheduler.step()
```

#### 2. Warmup（线性预热）

训练初期学习率从0线性增加到目标值：

```python
from torch.optim.lr_scheduler import LambdaLR

def get_warmup_scheduler(optimizer, warmup_steps, total_steps):
    def lr_lambda(current_step):
        if current_step < warmup_steps:
            return float(current_step) / float(max(1, warmup_steps))
        return 1.0  # warmup结束后由其他scheduler控制
    return LambdaLR(optimizer, lr_lambda)

# 通常配合Cosine Annealing使用
# Warmup + Cosine = Transformer训练的标配
```

#### 3. OneCycleLR

```python
from torch.optim.lr_scheduler import OneCycleLR

scheduler = OneCycleLR(
    optimizer,
    max_lr=1e-3,
    total_steps=num_epochs * len(dataloader),
    pct_start=0.3,        # 30%时间用于warmup
    anneal_strategy='cos', # 余弦退火
    div_factor=25,         # 初始lr = max_lr/25
    final_div_factor=1e4   # 最终lr = max_lr/25/1e4
)
```

OneCycleLR的特点：
- 先增后减的单周期策略
- warmup阶段：lr从低到高
- 退火阶段：lr从高到低
- 论文表明这种策略可以用更少的epoch达到更好的效果

#### 4. 线性衰减

```python
def get_linear_decay_scheduler(optimizer, warmup_steps, total_steps):
    def lr_lambda(current_step):
        if current_step < warmup_steps:
            return float(current_step) / float(max(1, warmup_steps))
        # 线性衰减
        return max(0.0, float(total_steps - current_step) / float(max(1, total_steps - warmup_steps)))
    return LambdaLR(optimizer, lr_lambda)
```

这是BERT预训练使用的策略，简单但有效。

#### 5. 对比实验

```python
"""对比4种学习率调度策略"""
import torch
import torch.nn as nn
from torch.optim.lr_scheduler import StepLR, CosineAnnealingLR, OneCycleLR, LambdaLR
import matplotlib.pyplot as plt
import numpy as np

def compare_schedulers():
    model = nn.Linear(10, 2)  # 简单模型
    num_epochs = 100
    steps_per_epoch = 10
    total_steps = num_epochs * steps_per_epoch

    schedulers = {}

    # 1. StepLR
    opt1 = torch.optim.SGD(model.parameters(), lr=0.1)
    schedulers['StepLR'] = (opt1, StepLR(opt1, step_size=30, gamma=0.1))

    # 2. CosineAnnealing
    opt2 = torch.optim.SGD(model.parameters(), lr=0.1)
    schedulers['CosineAnnealing'] = (opt2, CosineAnnealingLR(opt2, T_max=num_epochs))

    # 3. OneCycleLR
    opt3 = torch.optim.SGD(model.parameters(), lr=0.1)
    schedulers['OneCycleLR'] = (opt3, OneCycleLR(opt3, max_lr=0.1, total_steps=total_steps))

    # 4. Warmup + Linear Decay
    opt4 = torch.optim.SGD(model.parameters(), lr=0.1)
    schedulers['Warmup+Linear'] = (opt4, get_linear_decay_scheduler(opt4, 100, total_steps))

    # 记录学习率变化
    fig, ax = plt.subplots(figsize=(10, 6))
    for name, (opt, sched) in schedulers.items():
        lrs = []
        for step in range(total_steps):
            lrs.append(opt.param_groups[0]['lr'])
            opt.step()
            sched.step()
        ax.plot(lrs, label=name)

    ax.set_xlabel('Step')
    ax.set_ylabel('Learning Rate')
    ax.set_title('Learning Rate Schedules Comparison')
    ax.legend()
    ax.grid(True)
    plt.savefig('lr_schedules_comparison.png', dpi=150)
    plt.show()
```

**EDA (Easy Data Augmentation)**：
```python
import random

def eda_augment(text, alpha_sr=0.1, alpha_ri=0.1, alpha_rs=0.1, p_rd=0.1):
    """EDA文本增强：4种操作的随机组合"""
    words = text.split()

    # 1. 同义词替换 (Synonym Replacement)
    if random.random() < alpha_sr:
        idx = random.randint(0, len(words)-1)
        # 替换为同义词...

    # 2. 随机插入 (Random Insertion)
    if random.random() < alpha_ri:
        idx = random.randint(0, len(words)-1)
        # 随机位置插入同义词...

    # 3. 随机交换 (Random Swap)
    if random.random() < alpha_rs:
        i, j = random.sample(range(len(words)), 2)
        words[i], words[j] = words[j], words[i]

    # 4. 随机删除 (Random Deletion)
    words = [w for w in words if random.random() > p_rd]

    return ' '.join(words)
```

### Day 3: 正则化进阶

#### 1. Label Smoothing（标签平滑）

将硬标签(0/1)变为软标签：

```
硬标签: y = [0, 0, 1, 0, 0]  (one-hot)
软标签: y' = [ε/K, ε/K, 1-ε+ε/K, ε/K, ε/K]
```

其中 `ε` 是平滑参数（通常为0.1），`K` 是类别数。

```python
import torch
import torch.nn as nn

class LabelSmoothingLoss(nn.Module):
    def __init__(self, num_classes, smoothing=0.1):
        super().__init__()
        self.smoothing = smoothing
        self.num_classes = num_classes
        self.confidence = 1.0 - smoothing

    def forward(self, pred, target):
        """
        pred: (batch, num_classes) — 模型输出logits
        target: (batch,) — 真实标签
        """
        log_probs = torch.log_softmax(pred, dim=-1)

        # 创建软标签
        with torch.no_grad():
            smooth_labels = torch.zeros_like(log_probs)
            smooth_labels.fill_(self.smoothing / self.num_classes)
            smooth_labels.scatter_(1, target.unsqueeze(1), self.confidence)

        loss = (-smooth_labels * log_probs).sum(dim=-1).mean()
        return loss

# 使用
criterion = LabelSmoothingLoss(num_classes=10, smoothing=0.1)
loss = criterion(predictions, labels)
```

为什么Label Smoothing有效：
- 防止模型过于自信（输出概率过于极端）
- 鼓励模型学到类与类之间的关系
- 提高模型的泛化能力
- Transformer训练中几乎都使用Label Smoothing

#### 2. DropPath (Stochastic Depth)

随机丢弃整个残差块，训练时以概率p跳过某个block：

```python
import torch
import torch.nn as nn

class DropPath(nn.Module):
    """随机深度（路径丢弃）正则化"""
    def __init__(self, drop_prob=0.1):
        super().__init__()
        self.drop_prob = drop_prob

    def forward(self, x):
        if not self.training or self.drop_prob == 0.0:
            return x

        keep_prob = 1 - self.drop_prob
        # 随机决定是否丢弃（只对batch中的部分样本丢弃）
        shape = (x.shape[0],) + (1,) * (x.ndim - 1)
        random_tensor = torch.rand(shape, dtype=x.dtype, device=x.device)
        random_tensor = torch.floor(random_tensor + keep_prob)

        return x / keep_prob * random_tensor
```

### Day 4: 损失函数进阶

#### 1. Focal Loss

Focal Loss解决类别不平衡问题，让模型聚焦于难分类样本：

```
FL(p_t) = -α_t · (1 - p_t)^γ · log(p_t)
```

```python
import torch
import torch.nn as nn

class FocalLoss(nn.Module):
    def __init__(self, alpha=0.25, gamma=2.0, reduction='mean'):
        super().__init__()
        self.alpha = alpha
        self.gamma = gamma
        self.reduction = reduction

    def forward(self, inputs, targets):
        """
        inputs: (batch, num_classes) — logits
        targets: (batch,) — 类别索引
        """
        ce_loss = nn.functional.cross_entropy(inputs, targets, reduction='none')
        pt = torch.exp(-ce_loss)  # 正确类别的预测概率

        # alpha权重
        at = self.alpha * targets.float() + (1 - self.alpha) * (1 - targets.float())

        focal_loss = at * (1 - pt) ** self.gamma * ce_loss

        if self.reduction == 'mean':
            return focal_loss.mean()
        return focal_loss

# gamma参数的作用:
# gamma=0: Focal Loss退化为标准交叉熵
# gamma=2: 对容易分类样本(p_t接近1)的loss大幅降低
# 例如: p_t=0.9 → (1-0.9)^2=0.01, loss降低100倍
#       p_t=0.5 → (1-0.5)^2=0.25, loss只降低4倍
```

#### 2. Dice Loss

Dice Loss常用于分割任务，直接优化Dice系数：

```
Dice = 2|X∩Y| / (|X|+|Y|)
Dice_Loss = 1 - Dice
```

```python
class DiceLoss(nn.Module):
    def __init__(self, smooth=1.0):
        super().__init__()
        self.smooth = smooth

    def forward(self, pred, target):
        """
        pred: (batch, num_classes, H, W) — 预测概率
        target: (batch, num_classes, H, W) — one-hot标签
        """
        intersection = (pred * target).sum(dim=(2, 3))
        union = pred.sum(dim=(2, 3)) + target.sum(dim=(2, 3))

        dice = (2.0 * intersection + self.smooth) / (union + self.smooth)
        return 1.0 - dice.mean()
```

#### 3. 对比学习损失 InfoNCE

```python
class InfoNCELoss(nn.Module):
    def __init__(self, temperature=0.07):
        super().__init__()
        self.temperature = temperature

    def forward(self, z_i, z_j):
        """
        z_i, z_j: (batch, dim) — 同一样本的两个增强view的表示
        """
        batch_size = z_i.size(0)

        # L2归一化
        z_i = nn.functional.normalize(z_i, dim=1)
        z_j = nn.functional.normalize(z_j, dim=1)

        # 拼接所有表示
        representations = torch.cat([z_i, z_j], dim=0)  # (2N, dim)

        # 计算相似度矩阵
        similarity = torch.matmul(representations, representations.T) / self.temperature
        # (2N, 2N)

        # 正样本对: (i, i+N) 和 (i+N, i)
        # 排除自身
        mask = ~torch.eye(2 * batch_size, dtype=torch.bool, device=z_i.device)
        similarity = similarity.masked_fill(~mask, -1e9)

        # 标签: 正样本位置
        labels = torch.cat([torch.arange(batch_size, 2*batch_size),
                           torch.arange(0, batch_size)]).to(z_i.device)

        loss = nn.functional.cross_entropy(similarity, labels)
        return loss
```

#### 4. Triplet Loss

```python
class TripletLoss(nn.Module):
    def __init__(self, margin=1.0):
        super().__init__()
        self.margin = margin

    def forward(self, anchor, positive, negative):
        """
        anchor: (batch, dim) — 基准样本
        positive: (batch, dim) — 同类样本
        negative: (batch, dim) — 异类样本
        """
        pos_dist = (anchor - positive).pow(2).sum(1)
        neg_dist = (anchor - negative).pow(2).sum(1)
        loss = nn.functional.relu(pos_dist - neg_dist + self.margin)
        return loss.mean()
```

#### 2. 知识蒸馏

知识蒸馏的核心思想：用大模型(Teacher)的"暗知识"指导小模型(Student)学习。

```python
class KnowledgeDistillation:
    """知识蒸馏训练器"""
    def __init__(self, teacher, student, temperature=4.0, alpha=0.7):
        self.teacher = teacher
        self.student = student
        self.temperature = temperature
        self.alpha = alpha  # 软标签损失的权重

        # Teacher不需要训练
        self.teacher.eval()
        for param in self.teacher.parameters():
            param.requires_grad = False

    def distillation_loss(self, student_logits, teacher_logits, labels):
        """
        总损失 = α × 软标签损失 + (1-α) × 硬标签损失
        """
        # 软标签损失：Student和Teacher的 softened 分布的KL散度
        soft_targets = nn.functional.softmax(
            teacher_logits / self.temperature, dim=-1
        )
        soft_student = nn.functional.log_softmax(
            student_logits / self.temperature, dim=-1
        )

        soft_loss = nn.functional.kl_div(
            soft_student, soft_targets, reduction='batchmean'
        ) * (self.temperature ** 2)

        # 硬标签损失：正常的交叉熵
        hard_loss = nn.functional.cross_entropy(student_logits, labels)

        # 组合
        total_loss = self.alpha * soft_loss + (1 - self.alpha) * hard_loss
        return total_loss

    def train_step(self, inputs, labels, optimizer):
        optimizer.zero_grad()

        # Teacher推理（不计算梯度）
        with torch.no_grad():
            teacher_logits = self.teacher(inputs)

        # Student前向
        student_logits = self.student(inputs)

        # 计算蒸馏损失
        loss = self.distillation_loss(student_logits, teacher_logits, labels)

        loss.backward()
        optimizer.step()
        return loss.item()
```

**温度T的作用**：
- T=1：标准softmax，分布可能很尖锐（一个类概率很高）
- T=4：软化分布，让"暗知识"显现出来

```python
# 温度的效果对比
logits = torch.tensor([5.0, 1.0, 0.5])

for T in [1, 2, 4, 8]:
    probs = torch.softmax(logits / T, dim=-1)
    print(f"T={T}: {probs.numpy()}")
# T=1: [0.931, 0.017, 0.010]  非常尖锐
# T=2: [0.813, 0.103, 0.084]  开始软化
# T=4: [0.576, 0.236, 0.188]  明显软化
# T=8: [0.420, 0.303, 0.277]  接近均匀

# T越大，Teacher的知识越"模糊"但信息量越丰富
# T²的缩放是因为KL散度在高温下会缩小，需要补偿
```

        train_one_epoch(model, train_loader, optimizer)
        val_acc = evaluate(model, val_loader)

        # 报告中间结果给Optuna
        trial.report(val_acc, epoch)

        # 早停（如果中间结果不好就提前结束）
        if trial.should_prune():
            raise optuna.TrialPruned()

        best_val_acc = max(best_val_acc, val_acc)

    return best_val_acc  # 最大化目标

# 创建study并运行优化
study = optuna.create_study(
    direction='maximize',  # 最大化准确率
    sampler=optuna.samplers.TPESampler(seed=42),  # 贝叶斯优化
    pruner=optuna.pruners.MedianPruner()  # 中位数剪枝
)

study.optimize(objective, n_trials=50, timeout=3600)  # 50次试验或1小时

# 结果
print(f"最佳试验: {study.best_trial.params}")
print(f"最佳准确率: {study.best_value:.4f}")

# 可视化

fig.write_html("optuna_history.html")

#### 2. 学习率Finder

```python
def find_lr(model, train_loader, optimizer, criterion, init_lr=1e-7, final_lr=10, num_iter=100):
    """学习率查找器：从小到大试，找loss下降最快的lr"""
    model.train()

    lr_mult = (final_lr / init_lr) ** (1 / num_iter)
    lr = init_lr

    lrs = []
    losses = []
    best_loss = float('inf')

    for i, (inputs, targets) in enumerate(train_loader):
        if i >= num_iter:
            break

        # 设置学习率
        for param_group in optimizer.param_groups:
            param_group['lr'] = lr

        optimizer.zero_grad()
        outputs = model(inputs)
        loss = criterion(outputs, targets)
        loss.backward()
        optimizer.step()

        lrs.append(lr)
        losses.append(loss.item())

        # 如果loss爆炸就提前停止
        if loss.item() > 4 * best_loss:
            break
        best_loss = min(best_loss, loss.item())

        lr *= lr_mult

    # 绘制lr vs loss曲线
    plt.figure(figsize=(10, 6))
    plt.plot(lrs, losses)
    plt.xscale('log')
    plt.xlabel('Learning Rate')
    plt.ylabel('Loss')
    plt.title('LR Finder')
    plt.grid(True)
    plt.savefig('lr_finder.png', dpi=150)
    plt.show()

    # 选择loss下降最快处的lr
```

#### 3. 梯度检查

```python
def check_gradients(model):
    """检查模型梯度是否正常"""
    total_norm = 0
    layer_norms = {}

    for name, param in model.named_parameters():
        if param.grad is not None:
            grad_norm = param.grad.data.norm(2).item()
            total_norm += grad_norm ** 2
            layer_norms[name] = grad_norm

            # 检查异常
            if torch.isnan(param.grad).any():
                print(f"[WARNING] NaN gradient in {name}")
            if torch.isinf(param.grad).any():
                print(f"[WARNING] Inf gradient in {name}")
            if grad_norm > 1000:
                print(f"[WARNING] Large gradient in {name}: {grad_norm:.2f}")
            if grad_norm < 1e-8:
                print(f"[WARNING] Vanishing gradient in {name}: {grad_norm:.2e}")

    total_norm = total_norm ** 0.5
    print(f"Total gradient norm: {total_norm:.4f}")
    return layer_norms
```

## 六、自测题

### 题1：Cosine Annealing相比StepLR的优势？

<details>
<summary>参考答案</summary>

1. **更平滑的衰减**：StepLR是阶梯式下降（突然降低），Cosine是平滑曲线。平滑的变化不会对训练造成"冲击"

2. **自动调节**：Cosine Annealing不需要选择"在哪个epoch降低"这个超参数，只需要设总epoch数

3. **后期更精细**：余弦曲线在训练后期变化更缓慢，有利于精细调整参数

4. **实验效果好**：大量实验表明Cosine Annealing在大多数任务上优于StepLR

5. **配合Warmup更好**：Warmup + Cosine Annealing 是Transformer训练的标准配置

StepLR的典型问题：如果在错误的时机降低学习率，可能导致训练不稳定或错过最优点。
</details>

### 题2：Focal Loss如何解决类别不平衡？γ参数的作用？

<details>
<summary>参考答案</summary>

Focal Loss通过降低"容易分类"样本的损失权重来解决类别不平衡：

```
FL(p_t) = -α_t · (1 - p_t)^γ · log(p_t)
```

**γ参数的作用**（focusing parameter）：
- γ=0：退化为标准交叉熵
- γ=2（常用值）：对容易分类样本大幅降权

具体效果（γ=2）：
- 容易样本（p_t=0.9）：(1-0.9)^2 = 0.01，loss降低100倍
- 中等样本（p_t=0.7）：(1-0.7)^2 = 0.09，loss降低11倍
- 困难样本（p_t=0.3）：(1-0.3)^2 = 0.49，loss只降低2倍

在类别不平衡场景中，大量"负样本"（背景类）很容易被正确分类（p_t接近1），标准CE中这些样本的loss仍然不小，主导了总loss。Focal Loss让这些容易的负样本贡献极小，使模型更关注少数但困难的正样本。
</details>

### 题3：知识蒸馏的核心思想？温度T的作用？

<details>
<summary>参考答案</summary>

核心思想：Teacher模型（大、准、慢）的输出分布中包含"暗知识"——不仅仅是正确类别，还有类别间的相似度关系。例如识别一只狗的图片时，Teacher可能输出"狗:0.7, 猫:0.2, 车:0.001"，其中"狗和猫的相似度"是有价值的知识。Student模型通过学习这个软化后的分布，可以获得比直接学习硬标签更好的性能。

温度T的作用：
- T=1：标准softmax，分布尖锐，一个类概率很高
- T>1：软化分布，各类的概率差异缩小，暗知识更明显
- T越大，分布越平滑，类别间关系信息越丰富
- T太大也会导致信息过于模糊，通常T=3~5效果最好

损失公式中乘以T²是因为：高温下softmax的梯度被T缩小了T倍，乘T²补偿回来，保证梯度量级不变。
</details>

### 题4：贝叶斯优化为什么比网格搜索高效？

<details>
<summary>参考答案</summary>

1. **利用历史信息**：贝叶斯优化维护一个概率模型（高斯过程），每次试验后更新模型。新的试验基于历史结果选择最可能改进的参数。

2. **智能探索**：通过acquisition function平衡exploration（探索未知区域）和exploitation（在已知好的区域深挖）。网格搜索盲目遍历。

3. **避免浪费**：
   - 网格搜索：100个组合就要训练100次
   - 贝叶斯优化：10-20次就能找到接近最优的参数
   - 因为它能预测哪些区域值得尝试

4. **处理连续参数**：网格搜索对连续参数（如学习率）需要离散化，可能错过最优值。贝叶斯优化直接在连续空间搜索。

5. **支持剪枝**：结合Median Pruner，在训练中间阶段就判断哪些试验没有前途并提前终止。

类比：网格搜索是穷举法（时间复杂度爆炸），贝叶斯优化是二分查找+概率推断（大幅减少搜索次数）。
</details>

### 题5：训练loss不下降的常见原因有哪些？

<details>
<summary>参考答案</summary>

按优先级排序：

1. **学习率问题**（最常见）：
   - 太大：loss震荡不收敛
   - 太小：loss下降极慢或不动
   - 解决：用LR Finder找合适的lr

2. **梯度问题**：
   - 梯度消失：检查各层梯度范数
   - 梯度爆炸：使用梯度裁剪
   - NaN梯度：可能有除以0或log(0)

3. **数据问题**：
   - 标签错误：随机检查样本
   - 数据没打乱：模型学到的是数据顺序不是特征
   - 输入没归一化：数值范围差异大

4. **代码bug**：
   - 忘记zero_grad()：梯度不断累积
   - 损失函数选错：回归任务用了分类loss
   - train/eval模式没切换：BN/Dropout行为不同

5. **模型问题**：
   - 容量不足：模型太简单学不到
   - 初始化不当：全零初始化、初始化值太大/太小

**Debug策略**：先在小数据集（10个样本）上测试，确认能过拟合。如果连10个样本都过拟合不了，一定是代码bug。
</details>

## 七、Java开发者提示

### 1. 学习率调度 vs JVM参数调优

学习率调度和JVM垃圾回收器调优非常相似：

| 学习率调度 | JVM调优 |
|-----------|---------|
| StepLR | 分代GC（年轻代/老年代不同策略） |
| Cosine Annealing | G1 GC（平滑回收） |
| Warmup | JVM预热（JIT编译前用解释器） |
| ReduceLROnPlateau | 自适应GC（根据内存压力调整） |

```java
// JVM的"学习率调度"类似
-XX:+UseG1GC              // 选择策略（类似选择scheduler类型）
-XX:MaxGCPauseMillis=200  // 参数（类似设置lr参数）
-XX:+UseAdaptiveSizePolicy // 自适应（类似ReduceLROnPlateau）
```

### 2. 知识蒸馏 vs 代码Review与导师制度

知识蒸馏和软件工程中的知识传递完全对应：
```
Senior Dev (Teacher)    → BERT (大模型)
Junior Dev (Student)    → 小模型
Code Review (指导)      → 软标签 (暗知识)
编程规范 (硬规则)        → 硬标签 (正确答案)
```

Senior Dev不仅告诉Junior"这是对的"（硬标签），还会解释"为什么这样写更好"（暗知识）。温度T就像是解释的详细程度——T越大解释越详细。

### 3. 超参数优化 vs A/B测试

Optuna的超参优化和产品中的A/B测试思想相同：
```
A/B测试：对比两个版本的效果，选择更好的
Optuna：对比两组超参的效果，选择更好的

进阶：
多臂老虎机(MAB) → 贝叶斯优化
两者都是"在探索和利用之间找平衡"
```

### 4. 训练Debug vs 系统排障

训练Debug的方法论和Java系统排障完全一致：

| 训练Debug | 系统排障 |
|----------|---------|
| 检查输入数据 | 检查请求参数 |
| 检查梯度 | 检查日志 |
| 学习率Finder | 压测找瓶颈 |
| 小数据集测试 | 单元测试 |
| 过拟合检测 | 监控告警 |
| 梯度裁剪 | 限流/熔断 |

排障思路也一样：先缩小范围（小数据集测试），再定位问题（梯度检查），最后验证修复（重新训练）。

### 5. Label Smoothing vs 容错设计

Label Smoothing的本质是"不把话说死"——不给模型100%的确信度。这在软件设计中也很常见：

```java
// 不做Label Smoothing：硬编码的假设
if (status == 200) {
    // 100%确定请求成功
} // 但实际上200也可能是错误响应

// Label Smoothing思维：容错设计
if (status >= 200 && status < 300) {
    // 留有余地，不100%确定
}
```

核心思想：保持适度的"不确定性"，反而提高系统的鲁棒性。
